# {{SITE_NAME}}

A static marketing site: plain HTML + CSS, no build step, no framework.

- Pages are `.html` files in the repo root; shared styles live in `styles.css`.
- Keep copy as plain literal text in the HTML so it stays easy to edit visually.
- To add a page, create `about.html` (etc.) alongside `index.html` and link it
  from the nav in every page.
- No JavaScript is required; add a `<script>` only when an interaction truly
  needs it.
