# Security

If you find a security problem in Radial for Mac, please tell us privately instead of opening a public issue.

- Report it through GitHub: open the Security tab of this repository and choose "Report a vulnerability".
- Or email support@radial.to.

Include the app version, your macOS version and the steps to reproduce the problem.

This covers the code in this repository. For Radial Cloud, email support@radial.to.
